# Data Directory

This directory contains reference and processed datasets used by the
project.

Large satellite imagery is not stored in this repository.

Landsat and Sentinel imagery are accessed directly through the Google
Earth Engine Data Catalog.

## Reference Data

`reference/mining/`

Contains the interpreted mining Area of Interest used for the analysis.

## Processed Data

`processed/`

Contains selected derived vector datasets and statistical outputs.

Large raster products should remain outside the Git repository unless
specifically required for the portfolio.
