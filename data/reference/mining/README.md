# Mining Area Reference Data

This directory contains the mining Area of Interest used in the
Sangatta Mining Environmental Monitoring project.

## Dataset

`sangatta_mining_area`

## Source

Esri World Imagery

## Method

The boundary was manually digitized through visual interpretation of
high-resolution satellite imagery in QGIS.

## Purpose

The polygon is used as a fixed Area of Interest for:

- Landsat preprocessing
- Spectral-index analysis
- Annual 1990–2026 time-series analysis
- Land-cover analysis
- Change detection
- Mining disturbance assessment

## Limitation

The polygon represents an interpreted mining footprint.

It is not an official mining concession, permit, or cadastral
boundary.
