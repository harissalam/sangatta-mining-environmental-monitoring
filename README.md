# Sangatta Mining Environmental Monitoring

Multi-temporal remote sensing and GIS analysis of mining-related
landscape change in the Sangatta–Bengalon area, East Kalimantan,
Indonesia.

## Project Objectives

This project aims to analyze long-term environmental changes associated
with mining activities using satellite imagery, GIS, and Python.

The analysis will investigate:

- Vegetation change
- Land disturbance
- Surface water change
- Land-cover change
- Mining expansion
- Potential reclamation and vegetation recovery

## Study Period

1990–2026

## Technologies

- Google Earth Engine
- Python
- QGIS
- Landsat
- Sentinel-1
- Sentinel-2
- Git and GitHub
