# Project Overview

## Project Title

Sangatta Mining Environmental Monitoring

## Study Area

Sangatta mining landscape, East Kalimantan, Indonesia.

## Study Period

1990–2026

## Project Purpose

This project demonstrates the application of GIS, remote sensing,
Google Earth Engine, Python, and QGIS for long-term environmental
monitoring of a mining landscape.

The analysis focuses on detecting changes in:

- Vegetation
- Surface water
- Bare and exposed surfaces
- Landscape disturbance
- Potential vegetation recovery

## Area of Interest

The Area of Interest was manually delineated through visual
interpretation of Esri World Imagery.

The polygon represents the observable contemporary mining footprint
and is used as a fixed analysis area for the historical satellite
time series.

It should not be interpreted as an official mining concession
boundary.

## Main Outputs

- Multi-temporal satellite composites
- Spectral-index maps
- Annual spectral-index statistics
- Time-series charts
- Land-cover maps
- Change-detection maps
- Mining disturbance analysis
- Final GIS maps
