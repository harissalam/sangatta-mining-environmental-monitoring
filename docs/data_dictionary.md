# Data Dictionary

## miningArea

**Data Type:** Polygon / FeatureCollection

**Description:**  
Manually interpreted mining Area of Interest.

**Source:**  
Esri World Imagery

**Acquisition Method:**  
Manual visual interpretation and digitization.

**Purpose:**  
Fixed spatial boundary for the 1990–2026 remote-sensing analysis.

**Important:**  
This polygon represents an interpreted mining footprint and is not an
official mining concession boundary.
